# 모아 (MOA) · 체험용 모의 송금

모바일 금융 앱의 **모의 송금** 흐름만 담은 단일 HTML 시뮬레이터입니다.

실행 주소: https://charaing.github.io/toss/

> ⚠️ **체험용 데모입니다.** 실제 은행·금융 서비스와 연결되지 않으며 실제 돈은 이동하지 않습니다.
> 특정 금융 회사의 공식 앱이 아니며, 어떤 금융사와도 관련이 없습니다.

## 실행

`index.html` 파일을 브라우저에서 열면 바로 실행됩니다. 서버, 빌드, API 키가 필요 없습니다.

## 주요 기능

- 앱을 열면 바로 송금 화면: 은행 선택(검색) → 계좌번호 입력 → 받는 사람 이름 **직접 입력** → 금액 키패드
- 간단한 확인창(취소 / 보내기) 후, 내 계좌에서 받는 사람에게 날아가는 보내기 애니메이션 → 완료
- 가상 잔액은 완료 시점에만 한 번 차감되며, 거래별 고유 ID로 중복 차감을 막습니다
- 최근 보낸 계좌 자동 저장·중복 정리, 즐겨찾기, 메뉴에서 가상 잔액 확인과 앱 데이터 초기화
- LocalStorage 저장, 손상된 데이터 자동 복구, 새로고침 후 상태 유지

## 데이터와 개인정보

- 입력한 계좌번호와 이름은 외부로 전송되지 않고 브라우저 LocalStorage에만 저장됩니다.
- 계좌 존재 여부나 예금주를 조회하지 않습니다. 이름은 사용자가 직접 입력한 값입니다.
- 완료 화면은 이체 증빙이나 영수증으로 사용할 수 없으며, 모든 거래 화면에 '모의 송금' 표시가 유지됩니다.
